# 瞬光伴行 v0.7.5

本版将 Windows 安装和启动分成两个步骤，并修复 Windows PowerShell 5.1 误判兼容 Node.js 为不可用的问题。Linux 部署与应用功能不变。

## Windows 安装与启动

1. 首次运行请双击 `Install.bat`，选择完整或轻量安装。安装器优先复用兼容的 Python、Node.js，缺少时才准备经过校验的官方版本。QQ 与 LibreOffice 仍是可选指南，不会自动安装。
2. 安装成功后双击 `Start_up.bat`，服务就绪后打开浏览器。这个入口不下载运行时、不安装依赖、不构建前端。
3. 升级或修复时先停止后端，运行 `Install.bat`，成功后再启动。普通重跑沿用已有安装模式；若要切换完整／轻量或重新选择可选指南，运行 `Install.bat -Setup`。

从 v0.7.4 升级时，依赖或构建输入更新会触发就绪检查。看到提示时运行 `Install.bat` 即可，不需要删除 `data/`、已有虚拟环境或模型。使用 ZIP 更新时先备份 `data/`，解压新版到新目录再按上述顺序操作。

安装器不再把已解压的 Node 无法执行或版本不符统称为压缩包不完整；请按窗口中的实际错误排查。
