# 瞬光伴行 v0.6.1

本版加入内置办公技能、真实成品生成与定位批注修订。0.6.0 的聊天、记忆、天气、语音输入和文件任务继续保留。

## 办公成品

- 上传资料后，在聊天里要求生成 Word 报告、Excel 分析、可编辑 PPT 或中文 PDF。普通任务直接制作，复杂或有重要歧义时先确认提纲；后台分批阅读来源，按会话提交时的模型执行。
- Word 支持正文、标题、列表、表格、页眉页脚及图片；已有常规模板按段落或单元格局部修改，保留未涉及内容和基础排版。
- Excel 支持数字、公式和原生图表，公式通过 LibreOffice 实际重算后才发布；公式错误、缓存缺失、外部连接或不支持的复杂对象会明确失败。不会把缺失结果当成零。
- PPT 使用原生文字、表格、分类图表和图片，支持标题、表格单元格和图表数据定位修订；不会把整页截图当成可编辑 PPT。
- 支持 Office 导出 PDF，一个任务可同时交付可编辑原格式和 PDF；直接生成的中文 PDF 嵌入开源字体字形子集。只有 PDF 时，正文修订生成 Word 副本，允许版式变化。
- 基础图片操作支持裁剪、缩放、旋转和 PNG/JPEG/WebP 转换，处理 EXIF 方向并保留支持格式的透明度；本版不含按描述生图或语义改图。

示例：“按这两份资料做一份有标题、表格和来源说明的 Word 报告，同时导出 PDF”“汇总表格数据，保留公式并生成柱状图”“制作三页活动汇报 PPT，文字和图表要能编辑”。

## 定位批注

1. 在右侧文件预览或已完成的小光回复中选择文字，右键添加评论；也可使用对象旁的批注按钮或键盘菜单。
2. Office 可按段落、表格单元格或幻灯片对象定位；页面和图片支持框选区域。Excel 提供带坐标的工作表内容预览。
3. 连续保存多条批注草稿，可编辑、删除，刷新后仍可恢复。同一聊天的草稿和预览标签独立保留。
4. 批注随下一条消息统一提交，发送前不执行。回复修订新增完整回复；文件修改生成新副本，原件保留。
5. 修订结果关联批注，无法确定是否落实的意见提示人工核对。源版本变化、重复原文、冲突或无法映射的区域不应被猜测为已完成。

页面预览由实际渲染图像与内容定位组成，不是完整 Office 在线编辑器。PDF 的可选文字位于内容清单中，不是覆盖在原版页面上的文字层。区域批注提供位置上下文，不代表模型一定能理解图像；无视觉能力时仍按既有授权流程处理。

## 保存与安全

默认将成果保存到 `data/outputs/任务-<任务ID>/` 的新文件。授权目录中的模板可先导入处理副本；明确要求覆盖时，还会出现一次覆盖确认，检查源版本、保存恢复备份，再写入原位置。工作台提供恢复入口。

成果保存失败时保留已生成结构，可检查权限、文件占用或目录后重试；不会因此重复调用生成模型。任务卡只播报关键节点，完整成品和代码块不自动全文朗读。

## 依赖与内置技能

- 重新运行项目安装流程，以安装新增的锁定依赖 ReportLab 4.4.9。内置技能随源码提供，不需要安装 Codex 或 Hermes。
- Office 页面预览、Office 转 PDF、Excel 公式重算需要用户手动安装 LibreOffice。推荐位置为 `tools/LibreOffice/`，0.6.1 自动检测该目录。缺少引擎时内容阅读仍可用，并显示缺失能力。
- [LibreOffice 安装指南](LibreOffice-install.md) · [维护者 Releases 上传教程](LibreOffice-release-upload.md)。启动和安装脚本不会自动安装 LibreOffice；提供的 ZIP 是安装包集合，不是便携运行版。
- Word、Excel、PDF 部分工具选自固定提交的 Hermes Agent MIT 源码；PPT 采用 PPT Master 的规划思路及部分 MIT 包关系检查工具。完整来源、许可与适配记录见 `skills/vendor/`。没有移植上游完整 SVG、动画、配音和视频流水线。
- 中文 PDF 字体为 Noto Sans SC 的常规字重派生版本，原始版权、SIL OFL 许可和哈希保存在 `source/resources/fonts/`。用户不需要安装字体构建工具。
