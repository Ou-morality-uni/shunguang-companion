# 瞬光伴行 v0.5.5 更新说明

本版完善 0.5.3／0.5.4 的日常使用流程：在聊天里交付文件任务，长资料按任务范围分批处理，总结自动另存成品。Word／Excel／PPT 创作与编辑、PDF 导出、基础图片处理及 Office 页面排版预览安排到 0.5.6。

## 聊天附件与后台任务

- 聊天输入区新增附件按钮，也可直接拖入文件。每条消息最多附加 10 份，每份非空且不超过 20 MiB。
- 上传只保存本机副本；写下处理要求并发送后，才由聊天模型安排任务。上传、阅读、识别和总结分别记录，原文件不因上传而修改。
- 附件引用随对应消息保存，刷新后仍可预览或下载。PDF 可看页面图像；图片显示第一帧；Office 展示提取出的正文、表格、幻灯片内容和位置；代码／文本按行预览。
- 文件任务提交后立即返回，后台执行期间可继续聊天。文件操作沿用单工作线程，新的任务依次排队；最多 8 个正在执行或排队的任务。
- 聊天任务卡展示真实状态、阅读范围、已读内容、来源、授权提示与结果，可取消任务，也可通过自然语言要求查看或取消本对话任务。
- 暂停等待确认的任务释放执行位置，继续后重新入队。取消在安全边界停止，排队任务可在开始前取消。停止聊天回复、停止朗读与取消文件任务分别处理。
- 工作台保留完整记录、手动步骤、授权、备份及恢复入口；阅读操作可选择指定范围、整份阅读或关键词定位。

## 长资料阅读与续接

- 要求总结整份资料时，使用整份分批阅读；具体问题按关键词定位相关范围，并说明哪些范围交给了总结模型。统计、排名、合计和全局比较要求使用整份阅读。
- 整份模式支持跨越原来的单次文字、图像和读取范围上限，保存页／正文块／工作表行段／幻灯片／代码行游标。Excel 整份模式按行段续读，读取工作表实际列范围，最高遵守 XLSX 的 16384 列边界。
- 单次提取的文字与图像仍有边界，长文字及图像分别续取；不会把前 60000 字符直接当作整份总结输入。长资料先按来源分段归纳，再综合结果，保留引用位置。
- 每轮最多 40 批原文读取、20 次文件处理模型请求；图像识别、分段整理、最终总结及按需生成的阶段提示计入请求额度。聊天回复与现有记忆处理仍使用各自原有流程。
- 已知资料规模预计超过读取额度时提前说明；达到本轮额度后暂停，保留已读资料、游标和分段笔记，显示继续确认卡并给出 TTS 提示。只有用户点击继续才开始下一轮，不能由模型自行续批绕过确认。
- 继续使用同一任务和已完成笔记，不自动重试失败的付费请求。源文件、授权目录或替代模型配置发生变化时重新检查，避免混用不同版本或服务。
- 部分内容无法提取、没有定位到关键词、拒绝视觉授权、格式不支持或输出超限时，保留说明，不将局部结果称为完整理解。
- 任务卡的已读内容预览最多展示前 30 个内容块，以控制轮询体积；这与实际阅读范围分别标记，原文可通过附件继续预览或下载。

## 成果目录与总结文件

1. 展开聊天中的“文件任务与成果目录”，或前往工作台，粘贴本机已有文件夹的完整路径，明确授权并设为成果目录。
2. 总结在聊天任务卡中展示，同时在该目录下为本任务建立独立子文件夹，另存 `资料总结.md`。文件包含完整返回的总结、来源、阅读范围和处理说明。
3. 成品卡片提供实际保存文件的 Markdown 预览、下载、保存位置及简短说明；预览不再次调用模型，也不自动加载模型输出中的外部图片。
4. 尚未选择目录或原目录授权已撤销时，保留已完成总结并等待选定位置；点击保存后不重新调用总结模型。

本版总结始终生成新文件。已有 Office 文件的编辑和默认另存副本规则在 0.5.6 实现；只有明确要求覆盖时才覆盖并保留恢复备份。0.5.3 的手动 UTF-8 写入与恢复机制继续保留，工作台会明确提示已有文本将被替换并备份。

## 工作语音

- 只在开始、主要阶段变化、需要确认、完成、失败或取消时播报，连续小步骤合并；时间流逝本身不再触发过程闲话。
- 使用多组场景话术并避开近期重复。较长任务在真实阶段切换时可按需生成一句表达；生成不可用时使用场景台词，不影响任务。
- 超长资料确认和等待成果目录也有对应提示，说明真实状态。不会因提示语播放失败而丢弃文件处理结果。
- 完成提示与总结正文朗读分别控制；后台总结完成后，若当前聊天正在回复，正文朗读等待聊天回复结束后入队。历史事件不会在页面重载时重播。
- 沿用统一音频队列、独立工作提示开关、静音及框内静音规则：独立代码框、命令、JSON、日志及无语言标记的文本框内容不进入 TTS。

## 视觉授权与本机权限

- 已配置并确认支持视觉的当前模型直接处理必要图像；不支持或接口拒绝时，在聊天任务卡中选择替代视觉服务并授权。
- 指定范围模式仍限列出的图像；整份／定位模式的卡片会明确说明本任务这份文件的图像范围，授权不会扩展到其他文件或其他服务。
- 读取、预览、下载、任务控制与成果目录设置仅对本机开放；局域网登录及转发请求头不授予本机文件权限。
- 复用已有目录身份、路径越界、链接／重解析点、硬链接、受保护路径及文件哈希校验。附件或成品被外部修改、移动或撤销授权后，下载和预览会停止并说明原因。
- SQLite 迁移到 v6，新增任务对话关联、续接上下文和成果目录设置；迁移前沿用自动数据库备份，不清空聊天、记忆或旧任务。

## 使用限制

- 聊天自动安排文件任务需要当前聊天模型及接口支持工具调用；也可使用工作台手动提交。
- 关键词定位属于有范围说明的资料筛选，不保证语义检索召回；没有找到时会说明，可改用整份阅读。模型总结和识别仍需结合原文核对。
- 常规 `docx/xlsx/pptx` 内容提取不保证复杂文本框、修订、嵌入对象或完整排版；Office 页面预览放到 0.5.6。公式只读表达式与已保存缓存，不重新计算或刷新外部数据。
- 旧版 Office、宏格式、加密和损坏文件需先提供可读取副本；图片仍只处理第一帧。没有新增 OCR 引擎、命令执行、插件市场或 AI 生图服务。
- 本版代码与版本说明只准备到本地 `output/github-public`，不执行 Git 提交、推送或 GitHub 发布。密钥、个人配置、数据库、聊天、记忆、附件、成果、备份、日志和本地验收资料不纳入源码同步。

## 验证结果

- 后端完整测试：247 通过，21 跳过；跳过项为默认关闭的联网人格评测与可选检索依赖用例。
- 前端：13 个测试文件、70 项测试通过；TypeScript、ESLint、Prettier 与正式构建通过。
- 后端 Ruff 检查、格式检查及 OpenAPI 合约一致性检查通过。
- 新增实际文件测试覆盖长 Word、超出旧行列上限的 Excel、单个超长文本块、图像分批授权、工作量预测与续接、笔记复用、源文件变化、后台聊天并行、排队取消、预览／下载校验及本机访问限制。
- 浏览器使用独立临时数据库、虚构资料和明确标识的模拟模型，验证 Office 内容预览、成果目录授权、暂停后同任务续接、刷新恢复、整份末段进入总结、自动另存及实际成品预览。
- 未调用真实聊天、视觉或 TTS 服务；真实模型的总结质量、服务兼容性、耗时、费用与音色效果需结合用户配置验收。
