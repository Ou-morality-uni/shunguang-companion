# v0.7.1：稳定性、性能、可读性与两版交付

日期：2026-10-30。本地版保留 QQ 接入；公开版使用相同核心功能，排除 QQ 实现与服务器桥接服务。公开副本由用户自行提交上传，此文件不表示 GitHub 已发布。

## 本版改动

- 为最终模型请求加入可调整的上下文预算，包含工具定义和结果，保留当前完整轮次；无输出的临时故障最多重试一次，已有输出不重放。
- 修复未开始消费的流式响应留下运行占用、空工具结果、配置损坏恢复和安装输出编码问题；访问控制新增认证记录容量、真实中间件回归和桌面配置写入限制。
- 删除对话时清理独占的应用管理附件和成果，保护共享引用、外部工作区原文件及确认记忆。文件暂存与数据库操作具有恢复记录；未结束任务需先完成或取消。历史备份及另存副本不随删除抹除。
- 历史召回使用适配中文片段的 FTS5 候选索引，保留精确匹配与遗忘屏障；消息默认最近 200 条，可加载更早记录并增量对齐。流式正文和元数据索引分离，减少重复查找与写入。
- DNS 地址解析移到线程并缓存；工作事件和空闲文件预览减少轮询。普通请求有超时提示，服务端任务不因浏览器超时被假称已经取消。
- QQ 禁用时不再常驻高频轮询，队列按事件唤醒；手动摘要仍可离线排队，过期且无长期内容的隔离空库可回收，主人和派生事实保留。
- 共用回合、能力提示、路径闸门、任务模型及 Office 格式加工拆分，保留接口与文件权限语义。工具超时可配置；已有重任务取消检查点和 Office 子进程终止机制保留。
- 加入请求／回合标识、JSON 阶段耗时和净化后的错误栈位置；可得用量如实记录，未知用量与费用不填造。健康信息区分存储、配置与可选依赖，匿名 LAN 健康接口不披露配置细节。
- 加入 23 项固定离线 Agent 契约场景及显式付费授权的真实模型探测入口；离线输出是模拟数据，不代表真实人格或注入鲁棒性验收。
- 收敛字号和语义色板，拆分主题样式并加入颜色／字号／基础对比度检查。保留暖霞红金风格；修复焦点反馈、删除焦点恢复、完整回复播报、回复期间起草与指针合帧。陪伴设置默认打开光效，连接引导仍直达模型设置。
- 自动迁移前校验备份，成功后保留最近 5 份自动快照，手工备份不自动删除。

## 使用与数据

正常停止旧服务后，使用原启动入口运行新版本。升级前保留运行数据与备份；数据库升级后不要直接用旧程序打开，恢复时应停止服务并成套恢复程序、数据库及需要的文件。

自定义模型的 token 预算采用估算，需按厂商模型窗口填写。停止聊天不会撤销已完成操作，也不会自动取消已经提交的独立后台文件任务；请在工作台取消它们。

`data/`、迁移备份及另存文件均属于私人数据范围，不能随公开源码上传。模型与工具仍使用用户自己的服务，可能产生费用；没有可靠价格时不报告估算金额。

## 验证与限制

本地版后端 501 通过、21 跳过；前端 32 个文件／150 项通过。类型、Lint、格式、语义色板检查、OpenAPI 一致性及生产构建通过。跳过项为未安装的可选依赖及需要显式开启的真实服务测试。

使用隔离合成数据验收了 500 条消息的分页与草稿保留、桌面和 390px 手机布局、700／980／1190 断点附近的设置页面、默认光效设置及删除确认焦点。10,001 条合成消息、20 次样本的本机对照中，历史召回中位数由 7.687ms 降至 1.328ms，P95 由 7.941ms 降至 1.720ms；这些数值不代表所有设备与真实历史库。

真实收费模型、QQ 发消息、云主机长期稳定性与真实屏幕阅读器未由离线测试代替；本次未自动发送 QQ 消息或调用收费服务。未取得 React profiler 逐气泡渲染统计，也未完成全部页面的 200% 缩放和跨浏览器验收；样式门禁及合成会话检查不能替代这些证据。上下文 token 是估算，任意后台 Python 线程无法被强制终止。
