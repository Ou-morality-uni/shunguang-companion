# 瞬光伴行 v0.5.2

更新日期：2026-10-20。

本版集中优化叶瞬光的角色表达、基础背景知识和身世检索，解决“明明有角色经历，却把问题当闲聊、回答没有资料”的问题。

## 更新内容

### 身世与拜师问题能够触发检索

- 补齐青溟剑、仪玄、叶释渊、橘福福、潘引壶、般岳等角色实体，以及拜师、师门、身世、童年和秘境相关问法。
- “你拜师的经过是什么”“具体是哪一年、哪位师父领我进门的”等问题会补上叶瞬光作为检索主体，进入知识检索。
- 普通的“你怎么了”“你为什么不理我”继续按日常对话处理；用户记忆问题仍与角色背景分开。
- 检索候选进一步按主题筛选，减少把无关性格、童年片段用于回答拜师或秘境问题。

### 26 条基础角色事实每轮常驻

新增 `backend/prompts/profile.md`，与人格规则一起组装进每轮首条系统消息，覆盖师门关系、拜师经过、青溟剑、日记、桂花糕、芽芽等基础内容。

这些事实不依赖当轮检索是否命中；人物规则与事实分别按文件修改时间刷新缓存。第一人称事实描述的是叶瞬光，不会因此写成用户身份或共同经历。

### 自然表达与真实能力边界

- 保留“呀”“啦”“哦”和适量波浪号，以日常、郑重和少量剑主语气回应不同情境，减少客服式的资料汇报。
- 已有明确背景直接回答；缺少依据的年龄、年份或细节不编造，“记不太清”也不代替所有知识回答。
- 保留被直接问及 AI 身份、应用功能或出处时的坦诚说明，不用角色口吻掩盖实际情况。
- 写日记是角色生活习惯，不代表已经读写用户文件；用户记忆只有实际保存成功才能说记住了。
- 天气和网页结果依实际工具执行情况回答，语音及提醒仍由原有界面和控件管理，不虚构感官或执行结果。

### 新增截至 2.5 的剧情年表

新增 `source/resources/character/timeline.md`，整理旧都陷落、般岳送兄妹上山、拜仪玄为师、青溟剑与剑匣、澄辉坪往事以及 2.4—2.5 相关经历。

年表已登记在资源清单，保留内容哈希、来源范围和剧透标记。本机增量索引新增 8 个片段；真实 BGE-M3 检索已验证拜师原问题能命中新年表。年表根据已有归档整理，不代表新增了官方独立核实结论，也不补写未公开的具体年份或未完结结局。

### 版本标记与说明归档

项目元数据、后端 API、前端包及界面显示统一为 `0.5.2`。详细版本说明统一放在 `versions/<版本号>/README.md`，主 README 仅保留每版一句摘要及入口；旧版说明链接仍可使用。

## 升级方法

1. 停止后端，保留自己的 `data/` 目录和已有模型、资源文件。
2. Git 用户拉取最新代码；ZIP 用户更新程序文件，避免覆盖个人数据。
3. 运行 `Install.bat` 更新构建和资料索引，再运行 `Start_up.bat`。
4. 已安装环境也可在“陪伴设置”中重新构建本地知识索引，以载入新增年表。

本次没有新增数据库迁移，不需要重新填写现有模型或语音配置。
