# 瞬光伴行 v0.6.0

发布日期：2026-10-24。本版整合文件工作区、自动记忆、天气关怀、在线语音输入与界面交互。

## 文件与成果

- 新成果默认保存到项目 `data/outputs/任务-<任务ID>/`，无需选择保存位置。历史成果保留原路径和访问记录。
- 聊天显示简短状态、摘要及成果入口；读取范围、授权、继续、取消和完整内容移至按需打开的右侧工作区。
- 支持任务、原文件、Markdown 成果和旧对话来源的多标签预览；按聊天分别记住标签，返回或刷新后恢复。支持调宽、放大和窄屏返回。
- 完整总结保存为 Markdown，可预览、下载、查看位置和主动朗读。自动工作语音只播简短提示，主动朗读继续跳过代码块。

## 个人资料与跨聊天记忆

- 记忆空间可以填写称呼、常住城市和年龄；默认称呼为“小师妹”。资料与已有记忆统一保存，可编辑、删除。
- 聊天中的明确长期变更可自动更新资料，临时出行不覆盖常住地；较旧的后台提取不能覆盖更新的手工信息。
- 移除手动总结入口，后台分批整理用户消息并保存进度，相关话题自动检索旧聊天，可打开真实原话来源。
- 整理失败不阻塞聊天；在对应聊天继续交谈或重启后重试，设置关闭时暂停。记忆空间展示排队、整理、摘要数量及失败状态。
- 遗忘或更正会使受影响的旧来源及派生摘要失效；删除原会话后来源不可再查看。原聊天记录不会因删除一条记忆而被抹去。
- 密钥、密码类消息不进入自动摘要或跨聊天召回；角色扮演、假设和无原话支持的个人事实不自动保存。

## 天气与关怀

- 休息提醒新增多组话术并避免近期重复。
- 使用个人资料中的城市，通过前台轮询触发天气刷新，正常情况下缓存一小时；天气失败或过旧时退回普通提醒。同名城市会提示完善省份或国家。
- 提醒遵守原有开关、暂停、安静时段和去重规则；关闭网页后不继续提醒，重新打开不补发离线积压。

## 语音输入与模型选择

- 输入区支持点击开始、再次点击停止录音。在线转写后追加到可编辑草稿，由你确认发送；支持取消、时长/体积限制和跨会话结果隔离，录音期间停止 TTS。
- 在“声音与播放 → 语音输入”中配置 HTTPS 的 OpenAI 兼容音频转写接口、实际可用模型和密钥；可独立保存密钥，也可明确选择复用同源的已保存连接。录音不保存为附件。
- 输入区汇总所有已保存模型连接，按服务分组；每个聊天独立记住连接、模型与思考强度，新聊天使用全局默认。当前请求和排队的文件任务使用提交时选择。
- 按已适配服务和模型声明提供思考选项；未知服务保留其默认行为，不虚构支持。原生推理/工具续接信息按接口规则处理，不作为普通正文朗读或显示。

## 页面与交互

- 保留暖霞红金，三种背景共用一个全局渲染层，覆盖导航及设置遮罩；新用户默认 Dark Veil，保留原有背景选择与减少动画设置。
- 下拉菜单采用 Glide Select 风格的滑动高亮，侧栏、设置和资料标签增加选中移动反馈；保留键盘操作及焦点返回。
- 常用按钮增加柔和高光，执行中的主要按钮短暂显示边缘流光；搜索测试收为一个按钮。
- 去掉输入区“文字对话”“陪伴模式”标签，增大时间字号与对比度，优化预览滚动条和 Markdown 表格。

## 验证与边界

- 源码后端离线回归：290 通过、21 跳过；前端：17 文件、97 项测试通过，类型、ESLint、Prettier 和生产构建通过。
- 使用临时数据、假模型及独立端口验收聊天文件任务、超限继续、Markdown 成果、多标签、按会话恢复、键盘菜单与响应式布局；检查 1280、1088 和 390 像素宽度。
- 真实麦克风、真实在线 ASR、收费聊天/推理/TTS 服务，以及各种设备的帧率和浏览器兼容性尚未实测。替身测试与界面验收不代表真实服务已连接。
- 自动提取依赖所选模型，可能遗漏或误判；请在记忆空间更正。摘要辅助有限范围的相关性检索，不保证新聊天掌握所有历史细节。自动后台整理会额外调用所选模型，可在长期记忆设置关闭。
- 首版语音输入仅适配兼容音频转写接口，不能把支持文字或看图等同于支持音频识别。请填写服务商实际提供的模型 ID。
- Office 创作编辑、页面排版预览、PDF 导出和基础图片处理安排至 0.6.1；旧 `.doc/.xls/.ppt` 等仍需先另存为常规格式。
