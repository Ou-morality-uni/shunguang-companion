# 瞬光伴行 v0.7.4

- **QQ 群成员档案**优先使用发言人、明确的 `@` 与 QQ 号。短称呼需要明确提及，同名缺少区分信息时跳过。群摘要根据已采集消息识别相关成员，合并时继续使用原始消息作为依据，并保留逐条资料范围限制。
- **角色资料检索**先筛选有主题证据的资料，再按标题中的人物匹配排序。即使候选里有标题更像的无关资料，正文相关的候选仍可供模型引用。
- **QQ 排障**在「QQ 接入 → 聊天管理 → 消息 → 最新消息」查看最近一条已采集消息的处理状态与原因。状态包括未触发、限流、模型失败、正在投递及待确认。更早的记录继续显示各自状态。
- 修正搜索设置的计数提示，更新使用章节和开发环境说明。

Windows 继续使用 `Start_up.bat`。Linux 使用独立的 v0.7.4 轻量部署包。 [QQ 接入指南](../../docs/qq-setup.md) · [Linux 部署指南](../../docs/server-deployment.md)
