# 瞬光伴行 v0.5.6 更新说明

本版专注 Web 布局、排版与动态效果。暖霞红金风格继续保留，聊天和资料阅读获得更多空间，文件预览改为按需展开的独立面板。

上传前补充打磨仍沿用 0.5.6：主聊天页重新排布，并加入三种可切换的鼠标互动背景。

## 布局与阅读

- 取消固定右侧信息栏和大幅静态立绘展示；原始素材保留。
- 状态、工具入口和语音控制移到聊天顶部。语音支持进入设置、静音与播放期间停止，完整波形、重播等控制继续在声音与播放设置中提供。
- 顶部区分对话状态与后台文件任务状态，能显示排队、执行、等待确认和完成等实际状态。
- 左侧导航默认展开，可折叠为图标栏，并在本浏览器记住选择。图标保留名称提示和键盘访问方式；最近对话在展开侧栏后查看。
- 输入区改为单行起步、随内容增长；附件、语音、工具与发送操作保留。
- 调整正文、辅助文字、卡片、间距和色彩层次，减少长文与任务卡的阅读负担。
- 用户消息靠右使用气泡；叶瞬光回复靠左以正文展开，保留小头像，长回复、代码和表格获得充分阅读空间。
- 新聊天欢迎区缩小装饰，提供“聊聊今天”“总结资料”和“世界漫游”建议。点击只填入输入框并聚焦，用户可编辑后发送；文件任务仍需实际附上文件与确认发送。
- 修复聊天 Markdown 表格被显示成竖线文本的问题，使用标准 GFM 扩展呈现表格，宽表格与代码块在内容区域内滚动。

## 独立文件预览

1. 点击聊天附件或总结成品上的预览按钮，在右侧展开内容。
2. 桌面上预览与聊天并排，拖动中间分隔线调整宽度；键盘左右方向键也可调整，Home／End 调整到边界。
3. 点击放大按钮进入宽幅阅读，再点击还原并排；关闭按钮或预览内的 Escape 键返回聊天。

- 并排模式下可以继续聊天、处理后台任务，放大预览时保留聊天组件及其状态。
- 窄窗口采用覆盖式单栏预览，减少宽度挤压；提供焦点约束和关闭后的入口焦点恢复。
- 切换会话或页面时关闭旧预览，防止把上一份资料带到新的会话里。
- PDF 页码、图片、Office 提取内容、文本与 Markdown 成果继续使用已有读取能力。下载和查看保存位置等操作保留。
- 本版 Office 仍为内容与位置预览，原始页面排版预览安排到 0.5.7。

## 暖霞流光与交互反馈

- “沉浸光效”设置中提供 Dark Veil（柔光纱幕）、Gradient Blinds（渐变光幕）、Aurora（暖霞极光）三种背景，统一适配红金配色。首次默认 Dark Veil；此后在本浏览器记住选择。
- 整个背景响应鼠标，包括聊天区背后；固定阅读遮罩控制文字对比度，装饰层不拦截点击、文字选择、滚动和文件拖入。
- 三款背景按需加载，同一时间只运行当前选中的效果；切换时释放旧画布、图形资源和事件监听，渲染分辨率设有上限。
- 修正 Dark Veil 窗口缩放时重复分配不可变纹理导致的图形错误，并适配开发模式下的画布重建。
- 按钮、导航、任务卡和成果卡在鼠标靠近时呈现局部柔光。
- 预览展开有短暂入场过渡，任务完成有简短的金色状态反馈，需要确认的任务突出边框。
- 新消息、欢迎区及新出现的任务／成果卡采用约 0.25 秒的淡入和小幅上移；流式更新不反复入场，历史消息与已有任务回看保持稳定。
- 聊天阅读与预览时降低持续背景光效，正文、代码和表格保持稳定。
- 沿用沉浸光效开关、减少动态效果设置和系统偏好；触屏、关闭动效或图形能力不足时保留本地静态霞光，页面进入后台时停止持续动画。图形上下文丢失时回退静态背景，主要操作继续可用。
- 三款背景使用项目内的 React Bits 源码，无额外运行依赖；入场动画复用现有 Motion。聊天表格新增 `remark-gfm` 依赖，已写入依赖清单与锁文件。
- React Bits 来源、适配说明和完整许可见 [第三方声明](../../frontend/THIRD_PARTY_NOTICES.md)。普通用户运行本项目无需安装 Codex 或 MCP 服务。

## 验证

- 前端 81 项测试通过，包含原有导航、预览和任务回归，以及新增建议卡不自动发送、背景选择与恢复、切换时草稿保持、存储不可用、无 WebGL 时正常操作及 Markdown 表格／代码块测试。
- 关键新增交互按 TDD 执行：先验证缺失或错误行为导致测试失败，再实现并验证通过；现有聊天、文件、授权与语音相关前端测试继续通过。
- 类型检查、ESLint、Prettier 与正式构建通过。
- 首轮后端 API 与资源接口相关回归 20 项、OpenAPI 契约检查通过；上传前补充仅调整前端，本轮未重新运行后端检查。
- 使用临时数据库和模拟模型验收桌面并排预览、真实拖动与键盘调宽、长资料继续处理、总结实际保存和 Markdown 成果预览；检查手机、窄窗口与大屏布局。

浏览器验收使用隔离的模拟数据，未调用真实聊天模型或 TTS 服务。手机与大屏布局通过不同尺寸的浏览器测试外壳检查，未覆盖所有真实设备，也未给出未经测量的帧率结论。

上传前补充在浏览器中检查了 390×844、900×720、1024×768、1280×720 和 1920×1080 视口；三款背景均有实际渲染与连续画面采样，切换后旧图形资源清理、模拟上下文中断和无 WebGL 回退通过。后台停止与恢复使用隔离夹具模拟可见性事件验证，不将它等同于所有浏览器后台策略的实测；未做完整帧率、功耗或真实手机基准。
