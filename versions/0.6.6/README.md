# v0.6.6：阅读回到聊天，文件交付更简洁

发布日期：2026-10-27。

## 文件阅读与交付

- 阅读 Word、Excel、PDF 或图片后，总结直接进入原聊天正文，不再默认另存 Markdown。后台完成与消息写入在同一事务中保存，轮询、刷新或服务重启不会重复投递。
- 去掉聊天里的工具调用卡、重复任务标题、“预览资料”“状态与操作”及提取原文列表。原附件仍可预览；实际生成的文件保留紧凑缩图、预览、箭头下载和查看位置。
- 修改仍生成新副本，默认沿用对应文件类型，不自动额外导出 PDF。PDF 正文修改目前不能可靠保持原版式时，简短停止；明确要求转为 Word 时才使用现有转换能力。
- 超时显示一句提示及一个重试按钮。重试复用已读内容，仅延长该任务等待，不修改全局设置。必要的外部识别授权、删除清单、继续处理与停止操作仍可使用。
- 修复可复现的异常分类问题：模型阶段的超时不再因继承 `OSError` 被误报为磁盘或文件权限故障。历史失败任务的原始原因不能仅凭旧通用提示完整还原，本版未自动重放用户任务。

## 记忆与记录

- 主聊天不再提供“记住这件事”即时写入工具，沿用已有自动事实处理和后台记忆整理。聊天不展示内部记忆调用；记忆空间仍可查看、更正、删除和忘记。
- 上传记录显示当地日期及 24 小时制的时、分。
- 历史聊天和任务不回填、不自动重试；旧阅读任务只有显式重试完成后才投递一条总结。已失效的旧任务预览标签不再恢复，原附件和实际成果标签保留。

## 验证与使用

- 源码后端全量回归 404 项通过、21 项跳过；前端 137 项通过（27 个测试文件）。类型、ESLint、Prettier、Ruff、API 契约及生产构建通过。
- 本地公开副本从自己的目录运行后端：403 项通过、22 项跳过，Ruff 与契约检查通过；多跳过一项项目内 LibreOffice 安装探针。36 个相关交付文件与源码哈希一致，主 README 保持本次实施前内容。
- 用独立数据库、替代模型和合成 Word、Excel、PDF、图片实际操作浏览器：聊天总结、超时重试、真实 Excel 新副本与预览、删除授权拒绝、自动记忆管理、分钟时间、刷新与重启后不重复投递。
- 验收 1413×871 桌面及 390×844 窄屏的显示、输入、成果菜单和预览；核对 Excel 指定目标已清空，非目标内容、表头样式及合并区域保留。普通阅读未产生额外文件，拒绝删除后测试文件仍在。
- 未调用真实付费模型、TTS 或 ASR，未修改用户原件或私人记忆；替代模型验收不能保证真实模型每次都正确理解自然语言。未做真机手机、多浏览器或性能压测。
- 保留现有 PDF.js、选择控件和构建分包提示，没有新增依赖。仅同步到本地公开副本，不自动提交、推送或发布；本地结果不等于新的远程 CI 结果。

关闭旧后端窗口，重新运行 `Start_up.bat`，再刷新页面加载本版。已有错误副本不会自动修复；重新修改表格时请选择内容完整的原附件。
