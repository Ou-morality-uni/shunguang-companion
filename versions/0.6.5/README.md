# v0.6.5：编号批注球、可靠 Excel 修订与紧凑成果

发布日期：2026-10-27。

## Excel 修订

- 拒绝“新建模式却提供编辑指令”和 `sheets[].edits` 这样的混合结构，避免忽略修改内容后生成空表并显示完成。修改必须明确绑定原文件 `source`，参考资料 `sources` 不能替代原件。
- 后台生成的参数无效时，保留已读资料并显示具体纠正信息，不发布不符合结构的成果。继续使用现有调用预算，不自动猜测来源或重放旧任务。
- 修订保存后核对目标值、非目标内容与公式、合并区域、单元格样式及原有行高列宽。含公式的工作簿经过实际重算后，再核对内容、公式与合并结构；重算引擎可能规范化样式，因此不将它描述为逐项视觉排版验证。
- 原件保留，修改生成新副本；本版没有自动覆盖或修复旧的错误成果。旧空白副本不能恢复原表，重新修改应选择仍完整的原附件。

## 批注

- 用靠近所选单元格、文字或对象的小气泡替代居中大弹窗，不添加整页遮罩、模糊或交互锁定。
- 点击外部自动保存草稿并收起，原目标显示与待发送列表一致的编号球；空白新批注不生成草稿。保存失败保留输入和错误提示。
- 鼠标移入编号球展开原意见，不抢走聊天焦点；点击或键盘激活可以继续编辑。保存修改更新同一条草稿，不重复新增；触屏通过点击使用。
- 表格按资源版本与单元格恢复编号，聊天回复按消息定位到目标边缘；PDF/图片沿用页码与归一化区域。PDF 编号覆盖层独立于页面重绘，缩放、旋转后仍可打开原批注。
- 发送前保存当前编辑内容，保存失败不发送；慢请求不会把旧聊天的草稿带入新聊天。仍由用户统一发送后再安排修订，保存草稿本身不调用修改模型。

## 成果

- 已完成成果显示紧凑缩图、文件名和预览按钮；向下箭头图标用于下载。多个成果分别保留入口，失败、审批和重试信息继续可用。
- 复用现有文档预览制作首屏缩图，最大边 240px，延迟加载并在服务端按版本缓存；不支持或引擎不可用时回退文件类型图标。
- 右键“查看位置”打开 Windows 文件管理器定位成果，另有可通过键盘和触屏使用的菜单按钮。服务根据成果身份、版本与授权解析路径，不接受任意路径或命令；局域网来源不能启动服务电脑的文件管理器。
