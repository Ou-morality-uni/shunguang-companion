# v0.7.2：可选 QQ 公开接入与安装启动优化

本版包含此前尚未公开的0.7.1核心质量改进，并统一公开Web、可选QQ与Linux轻量部署源码。由使用者自行安装QQ桥接、登录并授权，不自动替人登录或发送消息。

## 使用变化

- Windows双击Start_up.bat进入首次向导：完整／轻量、QQ接入说明、LibreOffice安装指南分别选择。以后快速启动，依赖／前端输入变化时提示更新；不自动拉取源码。
- 优先复用兼容Python与Node，缺失时准备官方锁定版本到当前用户目录，校验下载，Python另验签名，不永久修改系统PATH。项目环境仍隔离，VC++运行库可能需要系统授权。
- 轻量模式跳过本地向量依赖和BGE-M3，保留桌面密钥保护、人格、记忆、声音、搜索与可选QQ；停止后端后运行 `Start_up.bat -Setup` 可以补装。模式切换不删除历史或旧权重。
- 安装与前台运行共用跨进程锁；修复安装器使用旧健康字段而未拦截运行服务的问题。重复启动、端口占用和失败重试提供提示，不强杀未知服务。
- QQ公开包含联系人／群独立权限、记录独立查看、主人私人记忆共享与其他范围隔离、按需图片授权、逐聊天表情控制、定时摘要和独立投递许可。群默认关闭聊天，摘要默认只在面板。
- Linux默认仅Web，不下载／运行NapCat；明确选择 `install.sh --with-qq` 才启用包内桥接，或按指南自行准备桥接。旧部署的桥接配置沿用，持久化与加密备份保留。
- 官方PyPI较慢时，可明确使用 `--pip-source tencent` 或 `aliyun`，默认仍为official，保留版本锁定和TLS，不改全局软件源；恢复默认参考MP3并纳入服务器包，避免新安装资源检查失败。
- 更新中英文README、安装清单、QQ指南、服务器部署与升级说明；公开导出保留QQ和隐私过滤，不包含作者数据、主密钥、登录状态、模型权重或本地验收材料。

0.7.1带来的上下文预算、有限重试、中文历史索引、消息分页、独占文件清理、净化诊断及可读性改进见[对应说明](../0.7.1/README.md)。其中旧版“公开不含QQ”是历史交付边界，本版已改为共同的可选QQ能力。

## 更新

停止后端，保留自己的data与备份，使用GitHub Desktop拉取或 `git pull --ff-only`，再运行Start_up.bat。首次使用新向导重新确认安装范围，不删除已有环境和数据。遇到源码冲突先处理自己的修改，不使用强制覆盖。数据库升级后不要直接用旧程序打开；备份恢复需程序与数据版本相配。

本地完整后端回归512项通过、21项跳过；后续新增的软件源和公开隐私检查另做相关回归通过。前端32个测试文件／151项通过，类型、Lint、格式、样式门禁、契约及生产构建通过。公开源码树独立后端511项通过、22项跳过，前端独立安装依赖与相同检查通过。官方Python安装器和Node归档SHA-256核验通过，Python的PSF签名有效。

真实Ubuntu服务器采用独立测试目录、镜像、合成数据和端口，验证512MB限制下的容器认证、合成对话、重启持久化、加密备份恢复，以及实际HTTP静态资源和登录检查；未改动原有服务。合成模型不是付费模型验收，禁网容器的进程峰值约135MB也不是整机占用。

未完成全新Windows虚拟机从零全量安装、真实QQ收发／识图、收费API、真实屏幕阅读器和24小时稳定性验收。模拟模型／桥接测试不能替代这些验证。首次运行需官方分发源网络，下载和完整索引可能耗时。

本版不增加QQ语音回复或搜索结果数量设置。不自动提交、推送或发布GitHub，更新提示的公网生效需维护者上传update.json和源码。
