# 瞬光伴行 v0.5.4

更新日期：2026-10-22。文件与任务助理升级的第二阶段。

本版在 v0.5.3 工作台基础上增加资料上传、六类文件阅读、多文件总结、视觉能力确认与替代识别授权，以及符合叶瞬光人格的工作语音。详细更新记录放在本目录，主 README 保留克隆、安装和使用说明。

## 上传与阅读资料

- 工作台可一次上传最多 10 份文件，每份最多 20 MiB；上传副本保存在本机 `data/attachments/`，不覆盖用户原文件，也不进入 Git 上传清单。
- 上传后自动填好阅读任务，核对范围和阅读要求后提交。也可选择已授权工作文件夹中的文件，或在本机聊天中交给叶瞬光处理。
- 阅读要求留空时只提取资料；填写要求后可让当前聊天模型总结、对比多个阅读步骤的结果。模型调用会按所选服务规则计费；失败不会自动重复付费请求。
- 文档、图像和工具返回内容作为资料，不能替用户授权、执行代码或写入用户长期记忆。

| 类型 | 本版读取能力与来源位置 |
|---|---|
| PDF | 按页提取文字；扫描页和内嵌图片进入视觉流程；可勾选“PDF 页面视觉理解”识别矢量图表及整页内容 |
| Word `.docx` | 正文段落、表格、内嵌图片、页眉和页脚；以正文块／节定位，不伪造渲染页码 |
| Excel `.xlsx` | 工作表、单元格位置、值、公式和已保存计算缓存；不执行公式、不刷新外部链接 |
| PPT `.pptx` | 幻灯片文字、表格、常规图表类别与数值、图片和备注；保留幻灯片及对象位置 |
| 代码／文本 | UTF-8 文本，按实际行号读取，不执行代码 |
| 图片 | PNG、JPEG、WebP、BMP、TIFF、GIF 等可解码格式；处理第一帧，按模型能力识字和理解图表 |

Office 旧格式、宏格式、加密或损坏文档需要先另存为可读取的常规副本；本版不自动执行宏或调用外部链接。复杂文本框、修订、嵌入对象和 Office 整页视觉布局不保证完整提取，结果会注明限制。

### 阅读范围与完整性

- 每个阅读步骤默认从第 1 个位置读取 20 个单位，可选 1～50 个单位；PDF 按页、Word 按正文块、Excel 按工作表、PPT 按幻灯片、代码按行。范围外内容不会被当作已经读取。
- 单份文档最多返回 60,000 个文字字符；单任务综合总结最多送入 60,000 个提取字符。达到上限时注明截断，能够续读时显示下一起始位置。
- 每个工作表最多读取前 500 行、100 列及 5,000 个非空单元格；公式没有缓存值时明确说明“未重新计算”。
- 每次文档阅读最多处理 8 幅图像，单图最多 1600 万像素，识别输入会缩放。未识别、被拒绝、超出范围或无法解码的部分保留说明。
- PDF 的文字顺序可能与视觉排版不同；Word 与 PPT 的内容提取不代表排版已经完成视觉校验。OCR 式文字提取也不等于完整理解所有图形。

## 视觉能力与替代识别授权

- 模型连接新增“图像理解能力”：未确认、已确认支持、不支持。切换模型、协议或地址后重新确认，不通过模型名字猜测能力。
- 可点击“测试图像理解”，向已保存的当前模型发送合成测试图，验证图像输入与基本识别；仅验证返回正确后才标为支持。也可依据已核实的接口能力手动设置。
- 当前模型已确认支持、且能处理本次输入时直接识别必要图像，不重复询问。普通文档能直接提取的文字不依赖视觉能力。
- 当前模型不支持、尚未确认，或接口拒绝图像时，任务停在“等待图像识别授权”。保留已提取文字与已经完成的识别，不反复将图片发送给拒绝输入的模型。
- 以叶瞬光口吻说明当前情况，授权卡明确列出文件、页／图像位置、所选模型、服务地址、是否向本机之外发送及可能费用。
- 替代识别复用已保存、已确认支持视觉的模型连接。没有可用连接时先配置，不把“同意授权”说成已经获得识别能力。本版没有内置本机 OCR 引擎。
- 同意仅授权本任务所列图像，随后继续原任务；不切换用户的日常聊天模型。配置或文件发生变化时重新核对，不能挪用旧授权。
- 拒绝后保留已读内容并明确标记未识别部分，可继续总结现有资料；不会发送给替代服务。识别、总结和取消均使用现有任务记录。
- Anthropic 兼容适配器增加真正的图片内容块，避免把图片消息序列化成普通字符串。

## 自然的工作语音

- 语音设置新增独立“工作语音提示”开关，与“自动朗读新回复”分别控制，共同尊重语音启用、静音和可用状态，复用现有 MiMo／百炼配置。
- 开始、整理、等待授权、完成、部分完成、失败、取消及恢复使用多组场景短句，避免紧邻重复；不每次都说“终于”，也不把“卷宗”“术法”机械塞进所有场景。
- 较长的读取、识别或总结阶段，可按需生成一句符合人格的工作中表达。生成不阻塞文件任务；不发送原文、文件路径或任务标题来生成这句提示，失败时不影响任务，也不自动重试。
- 提示依据真实任务事件。未完成、等待授权、失败或取消时，不播报“已经完成”；部分结果使用对应表达，并在任务卡保留文字记录。
- 工作提示、正文和手动播放共用一个播放队列。过时进度丢弃、重连不重复播报；取消任务清理关联提示，停止朗读或静音不取消文件任务。
- 工作台总结正文按自动朗读设置处理；聊天创建的任务由聊天回复朗读正文，避免再把任务总结重复念一遍。

### 代码框与文本框不朗读

自动朗读、手动播放及流式 TTS 都先过滤独立代码／文本块：包括有语言标识或无语言标识的围栏块、缩进代码块及独立 `pre`／`code` 块。即使开头的三个反引号被拆成多段流式返回，也不会提前送入 TTS。

框外自然语言继续朗读；显示、选择、复制和保存的原文保留。行内代码不属于本次独立框过滤范围。

## 升级与隐私

1. 停止旧后端，保留 `data/`、已有模型与资源文件。
2. 更新代码并运行 `Install.bat`，安装本版新增的 PDF、Office、图片解析依赖并重新构建前端，再启动应用。
3. 后端启动时先备份旧数据库，再自动迁移到结构版本 5；保留原有聊天、记忆、工作文件夹授权和任务记录。
4. 在模型连接确认视觉能力，按需保存其他视觉模型；在语音设置保存工作提示及自动朗读选项。

工作台、资料上传、视觉测试和授权接口仍仅供本机使用，局域网登录不会获得本机文件权限。文档与图片只在任务要求和已配置模型／明确授权的范围内处理；个人配置、密钥、聊天与任务数据库、上传附件、文件备份、日志、验收截图和本地维护计划均不随源码同步到公开副本。
