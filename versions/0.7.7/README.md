# 瞬光伴行 v0.7.7

## Windows 安装与启动

- 首次双击 `Install.bat`。安装器优先复用独立的 64 位 CPython 3.11–3.14 和 Node.js 24；缺 Python 时准备官方 3.13.17。只装基础，成功后启动项目并打开网页。
- 日常双击 `Start_up.bat`，它不会安装依赖。基础需要修复时，先停止后端，再运行 `Install.bat`，不需要删除 `data/`。
- 「陪伴设置 → 服务管理」提供基础修复指引、知识库安装、视觉模型配置测试，以及 QQ 官方桥接指南与连接入口。知识库仅在 Windows 主机本机模式安装，验收通过后不用重启。NapCat 和视觉模型服务不由项目安装。

## 附件与历史成果

- 保留文本、可提取文字的 PDF、DOCX/XLSX/PPTX 的上传、提问、总结和原件下载；视觉模型只处理明确授权的独立聊天图片。扫描版 PDF 暂不支持。
- 不再生成或修订文件，不再提供目录授权、原版面多栏预览、批注、浏览器 OCR、PDF 导出或公式重算。历史文件和已有备份不自动删除，既有成品可到「历史成果」下载。
- 已配置的 QQ、已可用的本地知识库及自动关怀、搜索、语音等行为沿用原配置。
