# v0.7.0：QQ 接入与后台群聊总结（本机版）

日期：2026-10-28。仅本地源码与构建更新，未同步 `output/github-public`，未提交、推送或发布；公开更新清单仍为 v0.6.6。

## 功能

- 在现有导航加入“QQ 接入”：连接与绑定、联系人、群权限、摘要和隔离记忆。
- 通过本机 OneBot v11 正向 WebSocket 连接独立 QQ 桥，包含 Token 加密、账号核对、重连、事件去重和请求关联。
- 复用原有角色、对话生成、知识检索与受限工具流程；QQ 不获得本机工作区、附件或配置管理权限。
- 主人一次性私聊码绑定；主人 QQ 私聊共享网页私人记忆。其他私聊、各群和群内成员事实使用独立数据范围，包含候选、遗忘、回忆和后台提炼。
- 每个群独立设置采集、关闭／@或指令／适度自然参与、角色知识库、图片识别、定时摘要及原群投递许可。所有聊天默认关闭。
- 图片按范围授权、提前保存允许的图片副本、按回复或总结需要识别并复用；授权签名失效时不静默换模型。语音暂不解析。
- 手动时间段、每天固定时间、每隔若干小时的后台摘要；增量窗口和每日固定时段；摘要默认面板保存，可选私发绑定主人或发回原群。
- 任务与投递分开保存；投递重试不再生成摘要，未知发送结果不盲目重发。长窗口按分段及分层合并，模型输入有边界。
- 原始 QQ 消息、图片和非主人 QQ 会话原文默认 30 天保留，可调整；摘要与派生事实保留到手动删除。不会随 QQ 清理删除原有网页私人记录。

## 使用

完整步骤见 [QQ 操作手册](../../docs/qq-operation-manual-0.7.0.md)，包含 **NapCat Windows 一键 Shell、Framework＋LiteLoaderQQNT** 及 SnowLuma 备选说明。

更新后正常重启叶瞬光后端，再进入“QQ 接入”。本机正式使用仍从根目录 `Start_up.bat` 启动，默认地址 `http://127.0.0.1:8000`。

桥接、QQ 和叶瞬光后端必须持续运行；关闭浏览器不停止后台任务，电脑休眠或关闭后端会停止。本版没有自动安装桥接或添加开机启动／系统服务。
