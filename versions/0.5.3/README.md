# 瞬光伴行 v0.5.3

更新日期：2026-10-22。文件与任务助理升级的第一阶段。

本版新增本机工作台，让叶瞬光可以在你明确授权的文件夹内完成基础文件任务，并留下可检查、可取消、可恢复的操作记录。

## 更新内容

### 工作台与文件夹授权

- 左侧导航新增“工作台”。填写本机已有文件夹的完整路径，点击“授权此文件夹”后，才允许对其进行文件操作。
- 授权后，可在工作台提交任务，也可以回到本机聊天中，让叶瞬光使用文件工具完成你的要求。聊天中的完成描述以真实工具结果为准。
- 支持撤销授权；撤销后停止相关任务并阻止后续访问，文件和恢复记录保留。恢复修改前，需要重新授权原文件夹。
- 工作台及聊天文件工具仅供运行后端的本机使用。局域网登录不会获得本机文件权限；原有手机聊天功能继续使用原有访问规则。

### 基础文件任务

本版支持已有目录中的普通文件：

| 操作 | 行为 |
|---|---|
| 列目录 | 返回文件与文件夹名称，最多展示 200 项，超出时标明截断 |
| 读取文本 | 读取 UTF-8 文本，最多返回前 16,000 个字符，超出时明确标记 |
| 创建／修改文本 | 写入完整 UTF-8 文本；覆盖已有文件前先保存备份 |
| 移动／改名 | 在同一授权文件夹内移动普通文件，不覆盖已有目标 |
| 删除 | 先显示整个任务清单，经本机用户明确同意后才执行 |

单个文件最多 20 MiB；单任务最多 50 步，写入文本合计最多 1,000,000 个字符。任务在应用内串行执行；取消和超时在文件操作步骤边界生效。单任务执行限时 60 秒。

同一任务不能重复修改同一路径。移动目标的父文件夹须已存在；本版不递归删除或移动整个目录。遇到循环改名等情况，应拆成独立任务并检查中间结果。

### 删除确认与访问边界

- 包含删除的任务先进入“等待删除授权”，确认前整份任务均不执行。用户可以同意或拒绝；聊天模型不能替用户授权。
- 授权绑定已保存的操作与文件状态。执行前如发现文件内容、权限或目标位置发生变化，停止并说明原因，不复用授权覆盖新内容。
- 检查相对路径、目录身份、真实路径、符号链接、Windows 目录联接／重解析点、硬链接及挂载边界，拦截路径越界、备用数据流和保留名称。
- 应用数据与凭据、`.git`、`.env` 等受保护内容不属于工作文件操作范围。
- 本版提供受限制的文件 API，不执行文件内容，不开放终端或任意命令。文件夹授权不等于命令执行沙箱。

### 操作记录、备份与恢复

- 任务与每步状态保存到 SQLite，工作台展示排队、执行、等待授权、完成、失败、取消和恢复状态。
- 修改前保存备份和内容校验值，写入前先保存操作日志；恢复时逆序处理已发生的修改。
- 新建文件可以移除，覆盖可以还原，移动可以撤回，已确认删除的文件可以从备份恢复。
- 恢复前核对当前文件和备份。文件被其他程序再次修改，或备份校验失败时，停止恢复，避免覆盖新的工作成果。
- 服务重启后，将未结束的任务标为中断。不会自动重放操作；可以检查记录，再恢复本次修改或重新安排任务。
- 文件备份保存在运行服务电脑的 `data/file-backups/`。升级时保留整个 `data/`；删除这些备份会失去对应的恢复来源。

### 统一工具调用

天气、网页搜索、保存用户事实和回忆对话改为同一个注册与调用入口，继续尊重各自开关、记忆依据和工具调用上限。仅在本机已有文件夹授权时增加文件工具。

较长的工具返回值保持有效 JSON 并明确标记部分预览，避免从任意位置截断后，模型把残缺结果当成完整资料。文件任务完整记录仍可在工作台查看。

## 使用与升级

1. 停止旧后端，保留自己的 `data/`、模型及资源文件。
2. 更新程序文件，运行 `Install.bat` 重新构建前端，再运行 `Start_up.bat`。已具备开发环境也可以使用原有前端构建流程。
3. 后端首次启动自动将数据库升级到结构版本 4，升级前备份原数据库；已有聊天、记忆和配置继续保留。本版没有新增第三方依赖。
4. 在本机打开“工作台”，先授权专用测试文件夹，尝试列目录、修改文本及恢复，再用于正式文件。

主 README 仅新增一句版本摘要并更新版本入口；详细说明保存在本目录。
