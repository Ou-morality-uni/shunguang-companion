# 瞬光伴行 v0.1.5｜维护修订

更新日期：2026-10-17。沿用 v0.1.5 版本号，覆盖此前说明中与本页冲突的三厂商语音和仅手动记忆方案。

## 本轮连接修订

DeepSeek 官方两种协议显式使用快速非思考模式，Chat Completions 单独适配流式工具回传；空文本和不完整流不再显示连接成功。百炼提供新版模型选择，切换时清空不兼容音色；连接成功与克隆合成成功分开判断，明确失败的创建记录可人工修正重试。调研依据和官方示例见 [接入说明](../../docs/model-connections.md)。

## 变化

- 百炼Qwen-Audio自动朗读升级为同任务持续追加文本，生成中即可开始发声；加入600ms短文本等待上限和约350ms音频预缓冲，正常衔接并在断粮后重建小缓冲。停止及配置变化立即关闭旧连接；完整成功后才缓存重播。手动播放及旧Qwen3兼容模型仍使用完整文字，小米不变。累计3000字符、输入等待18秒和总超时均有明确边界，不承诺网络异常时零停顿。
- 新完成的角色回复自动附一张红色人格表情，结合当前对话选择场景，优先避开最近使用的图片；无匹配或未返回有效场景时使用中性陪伴图。接入全部 44 张红色表情（含新增 30 张日常图），选择随消息保存，语音和复制文本不包含控制标记。见 [表情说明](../../docs/chat-stickers.md)。
- 修复百炼密钥无效时误弹“连接你的陪伴空间”的问题。只有本机服务明确要求局域网登录时才显示访问口令框；语音鉴权失败显示在对应设置中。
- 语音只保留小米 MiMo 与阿里云百炼，停用火山入口。各厂商配置与加密密钥分别保存，切换时不会把一家的密钥发送给另一家。
- 百炼设置页支持创建、保存、刷新、选择、复制和确认删除多个云端音色，后续按音色 ID 合成，无需再次读取原 MP3。适配 Qwen-Audio 3.1/3.0 与旧 Qwen-TTS 两种不同协议，音色必须与模型、账号和地域匹配。新增无文本模型检查、创建去重、超时待核实记录和审核状态展示。
- 小米改为引用服务电脑上的原 MP3/WAV 路径；验证文件不再复制录音或建立参考索引。百炼网页选文件只作本次创建上传；Qwen-Audio 使用厂商私有临时存储，48 小时后清理样本。
- 小米合并短句、串行合成，减少并发限流。区分 HTTP 429、认证、模型不存在和断流等错误；残缺音频不会作为完整成品缓存。
- 修复中文天气城市候选与行政区匹配；完善 Tavily/Wikipedia 认证、空结果及上游错误处理。公开搜索仍为尽力服务，不把零结果或无关结果显示成成功。
- 自动记忆明确自述，新聊天可按需回忆其他聊天的真实片段。手动总结保留为补充，提供编辑、忘记和自动记忆/历史召回开关；侧栏数量在回复后更新。
- 个人记忆和日常问题跳过世界观 RAG；知识候选按实体和主题再筛选，允许零结果。分别保存候选计数、实际上下文与最终引用，只把回答中引用的资料列为引用来源。
- 补强角色表达和真实记忆操作结果的衔接，减少日常对话中的技术说明；不以口头承诺替代实际记忆写入，不虚构工具结果或共同经历。

## 升级

1. 停止后端，保留自己的 `data/` 目录与资源文件。
2. GitHub Desktop 点击 **Fetch origin → Pull origin**。ZIP 用户更新程序文件，避免覆盖个人 `data/`。
3. 运行 `Install.bat` 更新环境并构建前端，再运行 `Start_up.bat`。
4. 打开正式服务的“陪伴设置”。已有火山用户需重新选择小米或百炼并填写相应配置；百炼旧音色不能直接用于新的 Qwen-Audio 模型。

数据库自动升级至版本 3，迁移前备份。升级后的数据库不直接交给旧版程序使用。聊天仍由 SQLite 保存，没有改为每段一个 JSON 文件；用户无需手动整理才能跨聊天记住。

## 验证与限制

本机后端154项测试通过、1项可选RAG测试在基础环境跳过；独立检索环境此前另通过8项检索测试。前端43项测试及类型、lint、格式和构建检查通过。新增同任务追加、提前返回音频、取消及完整缓存、WebSocket来源与局域网Cookie验证，以及音频预缓冲、短尾释放、连续排程和完整缓存重播回归。保留厂商401与本机登录区分、表情、工具、历史、自动朗读开关和长度边界用例。远端CI结果以GitHub Actions为准。

持续输入用当前百炼Qwen-Audio 3.1克隆音色做了一次短句真实验收：同一任务在文字提交完成前返回音频，首段PCM约1.285秒（不含大模型生成和浏览器缓冲），返回音频5.51秒。本次未创建音色，未做主观盲听或稳定网络时延承诺。

真实天气、Tavily、Wikipedia、公开搜索和小米合成已执行最小验收。百炼模型任务与临时上传凭证已验证；完整新版克隆与合成需用可用账号创建匹配音色后试听。没有进行同样本双厂商音质或延迟对比，不承诺未经实测的低延迟数字。

“忘记”阻止相应事实及已标记来源被再次自动召回，原聊天、操作记录和备份仍可能保留。共享记忆作用于同一服务数据目录，不等于跨电脑同步。自动提取与历史召回有范围和预算限制，角色自然度仍受实际聊天模型影响。
