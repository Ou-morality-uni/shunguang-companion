# 瞬光伴行 v0.6.2

本版围绕聊天文件体验、连续预览与定位批注进行改进，保留 0.6.1 的 Office 制作、修订、PDF 导出和基础图片处理能力。

## 文件与阅读

- 上传只保存附件；明确发送要求后才启动任务。普通阅读在对应聊天轮次展示简要结论，不再自动生成 `.md`。需要文件时可说“保存为 Markdown”“制作 Word 报告”等。
- 任务和成果固定在发起它的消息轮次，后续聊天会自然把它们向上推；“预览资料”打开来源，授权、取消、继续和恢复保留在“状态与操作”详情中。
- PDF、Word、PPT 使用 PDF.js 连续原版面预览，支持滚动、缩放、旋转与按需绘制。Word/PPT 页面由真实 LibreOffice 转换，Excel 保留坐标表格预览。移除手填页码、分离提取正文和旧框选条。
- 附件按钮简化为“预览”，带轻微悬停反馈；移除上传原件副本下载入口。生成的成果文件仍可下载。
- 工作台精简为最近 200 份上传记录及预览；文件夹授权和 Office 引擎检测移到“陪伴设置 → 工具服务”。原文件、已有成果、备份和聊天文件能力保留。

## 批注与识别

在原页面选中文字后右键“添加批注”；也可右键进入评论模式，点击高亮的文字行或图像对象写意见。批注先作为草稿，可连续添加、编辑和删除，随聊天消息确认发送。聊天回复批注仍生成新的修订回复并保留原文。

- 保存文件版本、页码、引用文字和归一化区域；缩放、旋转后将位置换算回原页。Word/PPT 引用唯一匹配时关联回可编辑源对象，重复或跨对象引用保留页面定位并提示核对。
- 扫描 PDF 或图片可以先正常阅读、整页/图像批注；主动点击“识别文字”后，才用本机 Tesseract.js 识别当前页并生成词级可选文字层，支持中英文、进度提示和取消。
- OCR 字典、工作线程和 PDF 字体/解码资源随前端构建从本站提供，不依赖运行时 CDN，也不会因这个按钮把资料转交额外在线识别服务。原有聊天模型视觉能力与替代服务授权规则继续有效。
- OCR 文字会注明需核对，低置信度处会提示。复杂表格、图像和未标记 PDF 无法保证语义分块；无法可靠识别时定位整页，不猜测精确编辑对象。PDF 正文修订仍交付 Word 副本，允许版式变化。

## 聊天、模型与设置

- 输入区合并为“模型名 · 思考档位”入口，按已保存服务分组，打开时刷新可用模型目录；失败时保留缓存并提示。语音输入移至发送按钮旁，仍先转为可编辑草稿，再由用户发送。
- 不显示“默认”档位；只列对应模型已声明的 Low / Medium / High / Extra High / Max 子集。仅支持开关时显示 On/Off，无可调思考能力时隐藏。首次优先 Medium，其次采用已核实常规档位；开关模型优先 On。有效的既有会话选择保留。
- 选择控件恢复清晰边框，增加选值淡入与滑动高亮；尊重减少动态偏好。温度、超时、输出上限、默认思考与视觉设置收纳到“模型高级设置”，接口地址与协议单独折叠。
- 聊天隐藏“回忆来源”，内部来源、编辑和忘记机制保留。回忆过滤工具报错、短寒暄、无信息的提问、重复内容和超过 48 小时的明显临时情况，保留有效偏好及摘要语义关联。规则不能保证所有自然语言判断都正确。
- 修复跨会话切换时旧批注提示短暂填入新聊天的问题；文件夹授权不会再意外保存其他工具设置。
- 文件任务参数校验返回具体字段与可修正范围，支持模型纠正后重试；不放宽路径、覆盖、删除授权和备份规则。旧失败记录缺少原始参数，不能认定其唯一历史触发字段。

## 更新方式

更新代码后重新运行 `Install.bat`，安装锁定的前端依赖并构建；已有环境也可在项目根目录运行 `npm --prefix frontend ci` 和 `npm --prefix frontend run build`。关闭旧后端，重新运行 `Start_up.bat` 并刷新网页。个人数据继续保存在 `data/`。

Word/PPT 原版面预览、Office 转 PDF 和 Excel 重算仍需要 LibreOffice；可继续使用项目 `tools/LibreOffice/`，参见 [安装指南](../0.6.1/LibreOffice-install.md)。不需要安装 Codex 或连接开发用 MCP。新增前端依赖、许可和资源构建脚本随代码交付。
