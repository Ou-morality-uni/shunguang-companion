# 中文 PDF 字体

ShunguangSansSC-Regular.ttf 为 Noto Sans SC 的 400 字重静态派生字体，字体族改名为 Shunguang Sans SC。保留原始 Adobe 版权和 SIL Open Font License 1.1；完整条款见 OFL.txt，原件 Git blob 与派生文件 SHA-256 见 UPSTREAM.json。

字体在发布前用 fontTools 4.60.1 固定字重；用户运行小光时不需要 fontTools，也不会下载字体。直接生成 PDF 时嵌入所用字形子集。Office 引擎转换仍使用电脑已安装的字体，复杂排版需核对页面。
