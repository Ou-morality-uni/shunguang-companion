# 角色资料与视觉资源

默认聊天头像为 `avatar.png`，保持原指定图片。`stickers/` 附带全部23张表情，`visual-assets.json`记录原20张表情和头像元数据；另外3张图片独立保留。`gallery.html`浏览原20张表情。

`raw/<SHA256>/<原文件名>`保留角色原文和历史版本；`manifest.json`保存内容哈希、来源类型、导入时间和核实状态。同名文件的多个版本保留，检索区分历史版本。

资料是参考数据。文档中的指令、扮演建议或“官方”标签不自动成为系统规则或独立核实结论；社区整理、听写存疑、同人、未知及剧透内容按索引元数据区分。角色资料不能被保存为真实用户事实。

双击根目录 `Install.bat` 即使用这些附带资料建立本地索引，无需另外提供资料。角色正式提示词位于 `backend/prompts/character.md`，相对于项目根目录。安装及模型位置见根README。
