# v0.7.1 Linux 服务器轻量部署

公开版仅包含网页与共用服务，不包含社交桥接进程。支持 Linux amd64；程序使用 server 模式，不安装本地向量模型。

1. 在开发电脑按主 README 安装依赖，并运行前端构建。执行 `python scripts/package-server.py --help` 查看打包输出参数，生成不带私人运行数据的部署包。
2. 在服务器准备 Docker 与 Compose，解压到例如 `/opt/shunguang`。包内 `manifest.json` 用于文件校验；不要手工修改已校验的部署文件。
3. 执行包内 `install.sh`，按提示填写管理密码。主密钥和聊天数据位于独立 runtime 目录，更新不会自动覆盖；密码和密钥不要发到聊天或放进 GitHub。
4. 建立 SSH 隧道 `ssh -N -L 18000:127.0.0.1:8000 用户名@服务器IP`，通过浏览器打开 `http://127.0.0.1:18000/` 配置自己的模型。未验证前不要把服务直接暴露公网。
5. 使用包内 `doctor.sh` 检查进程和配置；程序存活不等于模型可用。模型、语音、搜索均使用实际配置的外部服务，可能产生费用。
6. 更新和加密备份／恢复使用包内 `update.sh`、`backup.sh`、`restore.sh`，先查看各入口帮助及提示。恢复时停服，核对程序与数据库版本，不以旧程序直接打开新数据库。

2 GB 主机仅作为轻量试运行目标，实际内存与长期稳定性取决于负载；本次没有真实云主机长时间验收。原有 Windows 桌面入口不变，克隆和本地使用步骤见主 README。
