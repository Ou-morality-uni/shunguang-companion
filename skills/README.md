# 小光内置文件技能

这些技能由小光任务服务加载，不依赖 Codex 或 Hermes 主程序。请通过聊天交代目标并上传资料；模型按任务选择技能，执行工具负责本机文件操作。

技能说明不是权限授权。文件操作继续受项目文件夹授权、资源版本、路径和备份规则保护；模型不能通过技能执行任意终端命令。

Word 和 Excel 的部分生成工具选自 Hermes Agent，固定版本及逐文件哈希见 vendor/hermes/UPSTREAM.json，MIT 许可与版权保留在 vendor/hermes/LICENSE。项目适配的输入限制和质量检查高于原工具默认行为。

Office 页面预览、Office 导出 PDF 和 Excel 真实重算需要 LibreOffice。在设置的工具服务或工作台查看能力检测与官方安装指引，安装完成后点击重新检测。没有引擎时仍可阅读已有提取内容，不能将未执行的重算或页面检查视为通过。
